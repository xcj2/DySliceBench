# 基于测试生成与缺陷定位的动态切片数据集

## 项目简介

本项目旨在为软件测试与调试领域的研究提供高质量的动态切片数据集。我们基于两个广泛使用的缺陷基准数据集——Defects4J 和 Tests4Py，通过人工标注的方式，为其中的缺陷实例生成了对应的动态切片。

这些动态切片能够精确反映特定测试用例执行过程中所覆盖的代码语句，对于研究故障定位、程序切片、测试用例生成等方向具有重要价值。

重要说明：
由于部分项目的构建环境、依赖配置或兼容性问题，某些缺陷实例无法成功运行。所有运行失败的项目及其具体原因，已分别记录在defects4j_failure_reason以及tests4py_failure_reason.两个Excel文件中，以便研究人员查阅和筛选。
